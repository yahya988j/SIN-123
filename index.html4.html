ابحث عن أي موقع على Google Maps

أدخل Plus Code أو أي عنوان، واحصل على كل التفاصيل فورًا — بدون أي مفتاح API

أمثلة: 7FG8Q7VM+HR برج المملكة، الرياض

هذي الأداة تحوّل أي إحداثيات (خط عرض/خط طول) إلى Plus Code فورًا ومحليًا بدون إنترنت. هي لا "تفكّ" رمز العنوان الوطني المختصر (مثل TADA6376) لأنه يحتاج قاعدة بيانات البريد السعودي أولًا — لكن بمجرد ما تجيب الإحداثيات من خرائط العنوان الوطني أو تطبيق "عنواني" أو حتى بتحديد موقعك بالجوال، الصق الرقمين هنا وخذ الـ Plus Code فورًا.
